# Web Development Fundamentals

HTTP GET retrieves resources, POST commonly creates resources, PATCH partially updates them and DELETE removes them. Idempotent operations have the same intended server effect when repeated.

React interfaces derive output from props and state. State should be treated immutably so changes are detected predictably. Accessible forms require associated labels, keyboard operation and clear error messages.

HTML gives a page semantic structure, CSS controls presentation and JavaScript adds behavior. TypeScript adds static type checking to JavaScript so many mistakes can be found before runtime.

An API defines how software components exchange requests and responses. REST APIs commonly use JSON over HTTP, resource-oriented URLs and status codes such as 200 for success, 201 for creation, 400 for invalid input and 404 for a missing resource.

Authentication verifies who a user is. Authorization decides what that authenticated user may access. Passwords should be hashed, secrets should stay outside source code and protected requests should validate a session or signed token.

Deployment makes an application available in a target environment. A production deployment needs configuration management, HTTPS, logs, health checks, backups and a repeatable release process.
