# Mathematics and Statistics for AI

Vectors represent ordered numerical features. Matrices organize values in rows and columns, and matrix multiplication combines transformations. A dot product measures how strongly two vectors align and is widely used in linear models and neural networks.

Derivatives measure how an output changes when an input changes. A gradient collects partial derivatives for every parameter. Gradient descent updates parameters in the direction that reduces a loss function.

Probability models uncertainty. Conditional probability describes an event given known information, and Bayes' theorem updates a probability using new evidence. Expected value is the probability-weighted average of possible outcomes.

A population is the full group of interest, while a sample is the observed subset. Confidence intervals express uncertainty around an estimate. Correlation measures association but does not by itself establish causation.
