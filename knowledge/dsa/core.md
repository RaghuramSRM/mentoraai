# Data Structures and Algorithms

Binary search repeatedly halves a sorted search space and runs in O(log n) time. Hash tables provide average O(1) lookup when keys are distributed well.

Dijkstra's shortest-path algorithm assumes non-negative edge weights. Breadth-first search finds shortest paths in unweighted graphs.

Arrays provide indexed access, linked lists connect nodes, stacks follow last-in-first-out order and queues follow first-in-first-out order. Trees model hierarchy, while graphs model general relationships.

Recursion solves a problem by calling the same function on a smaller case. It needs a base case and progress toward that base case. Dynamic programming stores repeated subproblem results, while greedy algorithms make the best local choice when the problem structure justifies it.

Big O notation describes growth as inputs become large. Common time complexities include O(1), O(log n), O(n), O(n log n) and O(n squared). The practical choice also depends on memory, input size and data characteristics.
