# Data Science Fundamentals

Data science combines data cleaning, exploratory analysis, statistics and communication. The median is more robust to extreme values than the mean.

Data leakage occurs when training features contain information that would not exist at prediction time. A reproducible workflow documents transformations and separates training, validation and test data.

Descriptive statistics summarize data using measures such as mean, median, variance and percentiles. Probability describes uncertainty, while statistical inference uses samples to estimate properties of a larger population.

Data visualization should answer a specific question. Bar charts compare categories, line charts show change over time, scatter plots show relationships between numerical variables and histograms show distributions. Clear titles, units and labels prevent misleading interpretation.

Analytics turns data into decisions by defining a measurable question, preparing reliable data, calculating relevant metrics and explaining the result with its limitations.
