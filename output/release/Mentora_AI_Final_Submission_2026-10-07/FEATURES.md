# Features

## Learning

- Career-aware onboarding and initial assessment
- Topic scores with strong, average and weak bands
- Prerequisite-ordered personalized roadmap with mastered foundations, unlocking and progress
- Adaptive quizzes with scoring, explanations, history and next difficulty
- Grounded mentor responses with visible specialist routing and sources

## Career and engagement

- Required-skill comparison and ordered gaps for a target role
- Ranked project recommendations with start and progress tracking
- Certification and interview-preparation suggestions
- Curated research updates
- In-app reminders, recent activity and real date-based streaks

## Platform

- Registration, login and JWT authorization
- Per-user data isolation
- Offline demo provider and optional OpenAI provider
- Persistent ChromaDB retrieval over the local Markdown corpus
- SQLite development database, Alembic migrations and PostgreSQL-compatible configuration
- Responsive React/TypeScript client and FastAPI API documentation
