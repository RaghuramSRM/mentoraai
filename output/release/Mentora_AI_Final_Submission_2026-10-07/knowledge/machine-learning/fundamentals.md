# Machine Learning Fundamentals

Overfitting occurs when a model learns training noise and fails to generalize. Use a validation split for model decisions and preserve the test set for final evaluation.

Cross-validation evaluates a model across multiple data splits. Useful metrics depend on the goal: precision and recall matter for imbalanced classification, while MAE and RMSE describe regression error.

Supervised learning uses labeled examples for classification or regression. Unsupervised learning finds structure in unlabeled data through methods such as clustering and dimensionality reduction. Feature engineering converts raw inputs into useful model signals.

Linear regression predicts continuous values. Logistic regression estimates class probabilities. Decision trees split data using feature rules, while random forests average many trees to improve stability. Model selection should match the data, target, constraints and evaluation metric.
