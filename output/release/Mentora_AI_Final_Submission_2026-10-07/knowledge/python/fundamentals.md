# Python Fundamentals

Python functions are defined with `def`. Parameters receive inputs and `return` sends a value back. Lists preserve order and allow duplicates, while sets store unique values. Dictionaries map keys to values.

Generators use `yield` to produce values lazily. Calling a generator function returns an iterator, which is useful when a full result would consume too much memory.

List comprehensions build lists from an iterable using a compact expression. Context managers use `with` to guarantee setup and cleanup, which is useful for files, locks and database transactions.

Virtual environments isolate project dependencies. Type hints document expected values and help static analysis tools, while automated tests verify behavior. Exceptions should handle expected failures without hiding unexpected programming errors.
