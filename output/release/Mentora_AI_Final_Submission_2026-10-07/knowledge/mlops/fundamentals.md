# MLOps Fundamentals

MLOps applies software engineering and operational practices to machine-learning systems. It connects data preparation, training, evaluation, packaging, deployment and monitoring in a repeatable workflow.

Experiment tracking records datasets, parameters, code versions and metrics so a result can be reproduced. A model registry stores approved model versions and their metadata. Automated pipelines reduce manual differences between development and production.

Model serving exposes predictions through a batch process, API or streaming system. Containers package code and dependencies consistently. Continuous integration tests code and data assumptions, while continuous delivery promotes validated versions through environments.

Production monitoring covers latency, errors, resource use, input drift, prediction drift and outcome quality. Data drift means the input distribution changed. Concept drift means the relationship between inputs and the target changed. Teams need alerts, rollback plans and retraining criteria.
