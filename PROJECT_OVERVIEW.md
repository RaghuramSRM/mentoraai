# Project Overview

Mentora AI is a local-first learning and career-guidance MVP for students. Its core loop is: capture a learner profile, assess knowledge, generate a personalized roadmap, teach with a routed and grounded mentor, adapt quizzes from performance, recommend career skills and projects, and measure real activity.

The deliverable is designed for an honest college demonstration: every visible action persists, each learner sees only their own records, and offline mode does not pretend to call an external model. The optional live provider is isolated behind the same agent contract.

## Scope

P0/P1 includes authentication, onboarding, assessment, roadmaps, mentor chat, adaptive quizzes, career analysis, projects, research updates, progress, streaks, reminders, dashboard aggregation and responsive web UI.

P2 excludes external messaging, native mobile apps, LMS integrations, payments and marketplaces. Production deployment hardening is documented but is not represented as completed deployment.
